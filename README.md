# app-releases

Trang phân phối và cập nhật ứng dụng di động nội bộ (Android APK) cho **myDTS**.

## Cách sử dụng

1. **Truy cập web tải app:** Xem trực tiếp trên Vercel hoặc GitHub Pages.
2. **Khi có bản cập nhật mới:**
   - Vào [Releases](https://github.com/hoangdv198/app-releases/releases).
   - Tạo **New Release** mới (vd: `v1.0.1`).
   - Đính kèm file `mydts.apk` vào Release.
   - Bấm **Publish Release**.
3. Trang web Landing page sẽ tự động cập nhật số phiên bản, ngày phát hành và dung lượng file mới nhất 100%!
